# Euronics HR Command Centre

VS Code-ready static dashboard based on the supplied HTML prototype.

## Run locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension by Ritwick Dey.
3. Open `index.html`.
4. Right-click inside the editor and select **Open with Live Server**, or click **Go Live** in the bottom status bar.
5. Your browser should open at an address similar to `http://127.0.0.1:5500/index.html`.

## Files
- `index.html` - dashboard structure
- `css/styles.css` - dashboard styling
- `js/app.js` - dummy data, tabs, charts, modal logic

## Important
The current values are dummy/sample data. Replace the hard-coded values and the `MODAL_DATA` object in `js/app.js` when connecting the dashboard to live KEKA/HRMS/API data.
